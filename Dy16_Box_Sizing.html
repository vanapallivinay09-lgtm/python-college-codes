Box Sizing - Day 16

1. Universal Selector (*) - Reset

* { box-sizing: border-box; }

This applies to EVERY element on page - best practice! Put at top of CSS

2. content-box (Default - Problem)

width:200px + padding 20 + border 10 = 260px total! Breaks layout!

Total Width = width + padding + border = 200+40+20 = 260px

3. border-box (Solution - Use This!)

width:200px includes padding+border = 200px total! Perfect!

Total Width = 200px only! Padding & border INSIDE width

This is why Day 15 boxes were overflowing - content-box!

4. Real Example - 2 Columns 50% each

Without border-box, 50% + padding = >50% = breaks to next line

Col 50% + padding + border = still 50% (border-box)
Col 50% + padding + border = still 50% (border-box)

With border-box, 2 x 50% = 100% perfect row!

Interview Answer

Q: What is box-sizing?

A: content-box = width is only content, padding/border extra. border-box = width includes padding+border. Always use *{box-sizing:border-box} for responsive design.

Q: What is Universal Selector?

A: * selects all elements. Use for reset.
